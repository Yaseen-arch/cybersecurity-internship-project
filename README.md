# Cyber Security Internship Project

## Overview
This repository contains my internship project for the Cyber Security Internship program. The objective of this project was to analyze a vulnerable web application, identify common security issues, and implement basic security measures to strengthen the application.

## Application Used
- OWASP Juice Shop (Local installation)

## Work Summary

### Week 1: Security Assessment
- Application exploration
- Cross-Site Scripting (XSS) testing
- SQL Injection testing
- Automated vulnerability scanning using OWASP ZAP
- Documentation of vulnerabilities and improvement areas

### Week 2: Implementing Security Measures
- Server-side input validation using validator
- Password hashing using bcrypt
- Token-based authentication using JSON Web Tokens (JWT)
- Secure HTTP headers using Helmet

### Week 3: Advanced Security
- Basic penetration testing using Nmap
- Application logging using Winston
- Security checklist and final documentation
